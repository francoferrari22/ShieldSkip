IMPORTANTE
No existe una API de Android que permita obligar a cualquier aplicación a cambiar la velocidad o eliminar cualquier anuncio. ShieldSkip intenta todos los controles que la otra app expone a Accesibilidad. Cuando existe un control de velocidad accesible, Turbo intenta usar la opción más alta disponible.
